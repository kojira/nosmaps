# nosmaps UI mock

Nostr周辺ツールの探し方を比較するための、**操作可能な純粋静的サイト**です。

> **重要:** 掲載名は原則として架空です。状態（active / stale / dead / unknown）、観測日時、根拠、ログはすべてUI確認用のモックであり、実在サービスの稼働状況を示しません。Nostrには未接続です。

## 3案の狙い

- **A「目的から探す」** — 初心者向け。専門用語ではなく「何をしたいか」から候補へ進む。
- **B「一覧・絞り込み・2〜3件比較」** — 比較検討する人向け。高密度な一覧、複数条件、最大3件の比較で差分を掴む。
- **C「カテゴリを辿る探索」** — 周辺領域も発見したい人向け。カテゴリを歩き、検索語を決めずに探索する。

トップ画面には、比較してほしい観点（次の操作、到達速度、状態根拠への信頼、再探索したさ）を表示しています。

## 共通データ

全3案で `app.js` 内の同じ36件の架空データを共有します。カテゴリ、用途、環境、ライセンス、状態、判定根拠、観測日時、観測ログを持ちます。観測値はすべてモックと画面内で明記しています。

## 操作と確認手順

1. トップからA/B/Cのいずれかを開く。
2. 目的選択（A）、検索・カテゴリ・状態・環境フィルタ（全案）、カテゴリ巡回（C）を試す。
3. カードの「詳細を見る」から状態の根拠と観測日時を確認する。
4. 2〜3件の「比較」を選び、画面下の「比較する」から横比較する。
5. ヘッダーから「候補を投稿」「キュレーション」「作者訂正」を開き、入力・イベントプレビュー・未送信状態を確認する。
6. 各案下部の **UI STATE LAB** で loading / empty / error / partial / offline を切り替える。
7. 幅375px前後のモバイル表示、および Tab / Shift+Tab / Enter / Space / Esc での操作を確認する。

## Nostr未接続

候補投稿・キュレーション・作者訂正は操作イメージのみです。秘密鍵へのアクセス、署名、イベント送信、リレー接続は実装していません。フォーム送信後も「プレビュー確認済み（未送信）」になるだけです。

## 永続的なアーキテクチャ原則

**このプロジェクトは、バックエンド、専用API、永続DB、中央インデクサを未来永劫作りません。** 静的ファイルとして配信し、将来データ接続を行う場合もブラウザからNostr等の分散プロトコルを直接利用する前提です。

## ローカル確認

```sh
python3 -m http.server 4173
# http://localhost:4173/
```

ビルド工程はありません。`index.html` / `styles.css` / `app.js` がそのまま配信物です。過剰な依存を避けるため、アプリ本体のnpm依存はゼロです。
